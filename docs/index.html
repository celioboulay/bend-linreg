    4.The limit
    
  
    Bend's runtime stops on any natural number above 248 − 1. Before computing, fit checks that nothing it will compute can pass K = 247:
    
  
    n² · B² · max(2B, L) ≤ K
    
  
    n points, L the lcm of every denominator, B the largest |x·L| or |y·L|. Inputs over the limit get TooLarge instead of a wrong answer or a crash.
